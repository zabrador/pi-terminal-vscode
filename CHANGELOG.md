# Changelog

## 0.3.0

- Route Plannotator reviews from the Pi pane into VS Code on macOS/Linux when the Plannotator extensions are installed and browser routing is enabled.
- Keep the existing launch environment when routing configuration is unavailable or invalid.

## 0.2.1

- Use VS Code terminal theme colors when opening the pane or clicking Restart Pi.
- Share the same terminal reset sequence between startup and restart.

## 0.2.0

- Add a Restart Pi button to start a fresh process without reloading VS Code.

## 0.1.1

- Launch Pi through `cmd.exe` on Windows and use `/bin/sh` as the fallback shell on macOS and Linux.
- Document platform requirements and native packaging. Runtime verification currently covers macOS only.

## 0.1.0

- Add an interactive Pi terminal in the Secondary Side Bar.
